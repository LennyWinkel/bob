## *Idee*
Mithilfe von Abstandmessern und Kontrastsensoren werden wir ein Auto zum selbstfahren bringen.
Dafür wird ein ESP-32 benutzt, um die ganzen Information zu verarbeiten und die Tätigkeiten ausgeführt. 
Zudem wird per Web-App das Modelauto lenkbar sein.
